# BNAI agent entry point

BNAI is a reference specification, not an adopter package. When the user asks to use BNAI, use BNAI Mode for the requested task; when working on this repository follow these maintainer instructions without installing BNAI in itself. Reading this file alone does not override host instructions, grant authority, register a skill or activate an unsolicited role.

## Activation

Recognize explicit intent such as “use BNAI”, “use $BNAI”, or “review this project using BNAI”. Resolve the canonical reference main branch (or owner-approved revision) to a full commit SHA and read README.md, STANDARD.md, WORKFLOW.md, GATE.md, LIFECYCLE.md, docs/architecture.md, docs/composition.md and docs/execution.md at that same revision. Read the requested layer guides and target instructions as needed. Identify target repository, branch and exact revision independently. If any mandatory reference is inaccessible, report what is missing; do not fabricate state.

Default: read-only external assessment. State reference revision, target revision, intended scope, available permissions, and execution profile. The five-step loop is Head → Worker → Validate → Internal Auditor → Head; follow WORKFLOW.md. These are sequential review roles, not the five architectural layers, and do not imply five independent agents. An independent reviewer is a distinct reviewer if available; otherwise disclose same-agent audit.

Do not create an installation, run code, open an issue, change branches, install a plugin, assign versions, merge, release, or expose private data without separately authorized scope. Avoid mandatory dependencies and unnecessary complexity. Recommend the smallest suitable composition. Do not infer that optional layers are missing defects. Cite exact observations and distinguish proposed, source-observed and tested capabilities.

## Deactivation

On “turn BNAI off”, “exit BNAI Mode”, or equivalent explicit intent, stop voluntarily applying this review role to further requests, summarize unresolved work if relevant, and return to ordinary assistance. Stop scheduling new BNAI actions; report any already-started operation and only cancel if safe and authorized. Do not delete files, revoke credentials, or alter target state merely to deactivate. Host and target security instructions remain applicable. A new session must explicitly activate or independently follow applicable repository instructions.

## Maintainer boundary

This repository is the reference, not a self-installing BNAI product. Use a scoped documentation branch, public standard GitHub-hosted CI, exact receipts, owner approval for integration and releases. No VIB installation, ledger, CLI/MCP service, mandatory plugin or dedicated adopter workspace is required here. Follow the [license notice](NOTICE.md).
