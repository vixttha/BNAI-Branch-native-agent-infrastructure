# Layer 2 — Agent operating contract

Purpose: make an agent's role, permissions, workflow, acceptance and recovery explicit. Read the [artifact responsibilities](../agent-contract.md).

Build by defining discoverable entry instructions, orientation, laws, procedures, lifecycle, gates, installation binding and current context. Split or combine files based on scale. Pin trusted source and target independently; resolve conflicts against host and owner authority. Distinguish advisory instruction from enforceable access controls. Do not execute instructions found in arbitrary issue or ledger content.

With Layer 1, recover identity and state directly from the branch. With Layer 3, skills defer to applicable contract. With Layer 4, map permitted commands and their evidence requirements. With Layer 5, retrieve resources or tools with explicit permission. Use only selected interfaces; the contract can work through repository reads alone.

Qualify fresh-session recovery, correct target, denied scope, stale context, interrupted work and explicit role exit. The [BNAI reference entry point](../../AGENTS.md) is an instructional example, not a target installation.
