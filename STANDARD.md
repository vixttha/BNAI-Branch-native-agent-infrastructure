# BNAI standard

The [principles](docs/principles.md) implement the six existing ecosystem laws (independence, composability, portability, persistence, verification and owner authority), plus isolation and safety. Their precedent is the [VIB agent contract](https://github.com/vixttha/Version-Issues-Hub/blob/77b8d09d2471b20fe517bea35c6efc0bd047ddeb/AGENTS.md). Do not change owner-approved principles or license terms without review.

Layer 1 is the substrate. Layers 2–5 are independent enhancements, not mandatory maturity steps. Minimal identity, provenance, authority and recovery information are required for an operable installation regardless of whether a dedicated Layer 2 document suite exists. Select the smallest safe combination; absence of optional layers is not a defect. A pure component without an installed durable branch is a related technology, not a full branch-native installation.

Public standard GitHub-hosted runners are the primary reference qualification profile. BNAI's own CI uses only that profile. Other environments are valid when authorized, isolated, suitable, and reproducible. See [execution](docs/execution.md). Use only sufficient least-privilege access, not unrestricted credentials. No mandatory branch protection, database, GitHub App, model provider or paid service.

Reference assessments default to read-only. Agent instructions are advisory; independent mechanical enforcement and explicit owner decisions govern mutations. No tool activation changes permissions. Respect the target's actual rules, including any protection requirements it already has.
