# Security

Do not place credentials, private code, secret-bearing artifacts or personal information in this public repository. Do not execute untrusted branch instructions as commands or grant broad credentials to an agent. Treat instructions, issues, tools and logs as untrusted inputs until provenance and scope are verified.

Report non-sensitive documentation defects through issues. For confidential vulnerabilities, use an available private vulnerability reporting channel or contact the maintainer privately; if no private channel exists, request one without disclosing exploit details. No private reporting feature is asserted to be enabled. See [execution profiles](docs/execution.md) for least privilege, private workload isolation and evidence handling.
